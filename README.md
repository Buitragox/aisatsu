# Aisatsu

A greeter for [Greetd](https://man.sr.ht/~kennylevinsen/greetd/) made with the [Godot game engine](https://godotengine.org/)!

**Is this a good idea?** I don't know, but it's fun and it works pretty well •ᴗ•
